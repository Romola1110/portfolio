# 寄情于物 · 设计说明 v2

## 体验结构（三层，避免一屏堆满）

```
门厅（默认）
  └─ 欢迎诗 + 「在此稍作停歇」
内室（点击后）
  └─ 赠礼互动：拆开礼物 → 随机一件 + 赠言
展匣（再次点击）
  └─ 全部手作网格 + 分类筛选
```

---

## 概念语气

- **不是商店，是角落**：欢迎来到我的世界，欢迎驻足
- **不是抽签，是赠礼**：偶然相遇、轻伤轻放、与你分享
- **自然休闲**：纸感、丝带、衬纸框；不喧闹、不堆满

## 你需要准备的素材

### 1. 拍摄（优先）

| 项目 | 建议 |
|------|------|
| 数量 | 每类 2–4 件，共约 10–15 件即可上线 |
| 画幅 | 长边 **1200–1600px**，竖版为主 |
| 光线 | **自然光 + 纯色或木纹桌面**，避免杂乱背景 |
| 角度 | 正面或微俯 15°，物品完整、留一点呼吸边 |

### 2. 每件需提供

```
文件名：calligraphy-01.jpg（类别-序号）
中文名：雨夜小楷
一句物记：窗上的水痕，成了字距。（展匣卡片下）
赠言 verse：字越小，心越静。（礼物卡上）
小故事 story：2–3 句，点击弹层用（可选）
类别：calligraphy | dye | bookmark | paper
装帧类型：cutout | soft（见下）
```

### 3. 图片处理三档（不必全抠）

#### A · `cutout`（抠图 PNG）— 推荐 4–6 件
- **适用**：书法单页、书签、折扇、轮廓清晰的小物
- **工具**：remove.bg / Photoroom / PS 钢笔（批量可用 Photoroom）
- **导出**：PNG 透明底，长边 1200px
- **放**：`assets/things/xxx.png`，JS 里 `matStyle: 'cutout'`

#### B · `soft`（不抠，衬纸裁切）— 默认大多数
- **适用**：染卡、明信片、背景尚可的照片
- **做法**：不抠图；网站用 **宣纸衬 + object-fit: cover** 裁掉杂乱边缘
- **拍摄时**：物品占画面 70%，四周留纯色边，后期最省事
- **放**：`assets/things/xxx.jpg`，`matStyle: 'soft'`

#### C · 模糊净化（仅拍摄补救）
- **适用**：背景略乱、暂时不想抠
- **Lightroom/手机**：略增虚化或压暗四角 vignette
- **或**：我方可加 CSS `mat-soft` 内晕影（已内置）

### 批量工作流建议

1. **先拍一轮**，按四类分文件夹  
2. **挑 4–6 件最满意的抠 PNG**（礼物池高频件 + 展匣封面感强的）  
3. **其余全部走 B 档**，统一衬纸框  
4. 把路径填进 `assets/things-section.js` 的 `THINGS_DATA`

示例：
```javascript
{
  id: 'b1',
  name: '银杏叶签',
  image: 'assets/things/bookmark-ginkgo.png',
  matStyle: 'cutout',
  verse: '翻页时，请轻一点。',
  // ...
}
```
