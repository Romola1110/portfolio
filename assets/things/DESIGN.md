# 寄情于物 · 设计方案

## 概念：匣中签 · 物有灵犀

把杂乱的手作物件，收纳成「可翻阅、可偶遇」的展匣体验。用户不必一次看完——**抽签**让每件小物带着一句短笺出现，像从旧木匣里摸出一件带着体温的东西。

---

## 一、内容架构

| 层级 | 名称 | 作用 |
|------|------|------|
| 引语 | 物候笺 | 一句主文案 + 英文副题，定调「物轻情重」 |
| 互动 | 签筒 | 求签 → 随机一件 + 签文 + 微故事 |
| 分类 | 四匣 | 书法 / 染卡 / 书签 / 纸艺（可筛选展匣） |
| 陈列 | 展匣墙 | 统一装帧的图片墙，可点看大图 |
| 收束 | 物记一行 | 每件物底部一行「物记」，不喧宾夺主 |

### 推荐分类与文案方向

**书法** — 墨痕是时间的落款  
**染卡** — 色落在纸上，像情绪找到了形状  
**书签** — 夹在书页之间，替思绪留住页码  
**纸艺** — 折扇、明信片；纸薄，却承得住一段路

## 二、图片处理策略（不必全部抠图）

| 等级 | 适用 | 做法 | 工作量 |
|------|------|------|--------|
| **A 衬纸框**（默认） | 背景一般、类型混杂 | 统一「宣纸衬 + 细框 + 轻阴影」，图 `object-fit: contain`，杂色背景被衬纸吃掉 | 低 |
| **B 柔边晕** | 背景尚可、边缘略乱 | CSS 径向遮罩 / 内描边，不抠 PNG | 很低 |
| **C 精修抠图** | 3–5 件代表作 | 仅 hero 抽签高频件抠图，其余用 A | 中 |

**结论：不需要一张一张全抠。** 用统一装帧建立秩序；只有封面级、签筒常出的 3–5 件值得精修。

---

## 三、UI 结构（与主站呼应）

- 右对齐区块（`align-right`），与主站 `#things` 一致  
- 季节色 `var(--accent)`，毛玻璃衬底，古典字体标题  
- 图片为主：文案压在衬纸/展签上，而非大段正文  

---

## 四、互动：抽签

1. 用户点 **求一签** → 签筒轻摇  
2. 抽出一件物：图 + 名 + 签文（15–25 字）  
3. **再求一签** / **收入展匣**（高亮对应格子）  
4. 可选：每日首签固定（`localStorage`），增加回访感  

签文语气：含蓄、私密、像写给物件的便笺，而非说明书。
